# ☕ Coffee Corner

A responsive coffee shop website that presents the menu, a special offer, customer reviews, and contact details. Built as a front-end practice project to show layout, styling, and clean UI design.

🔗 **Live Demo:** [malar172.github.io/Coffee-shop](https://malar172.github.io/Coffee-shop/)

## ✨ Features

- Responsive layout for desktop, tablet, and mobile
- Navigation bar with links to Home, Menu, About, Offers, Testimonials, and Contact
- Hero section with a "View Menu" call-to-action
- Menu cards with images, descriptions, and prices
- About Us section
- Happy Hour special offer
- Customer testimonials
- Contact page
- Footer with social media icons

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/malar172/Coffee-shop.git
   ```

2. Go to the project folder:

   ```bash
   cd Coffee-shop
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
